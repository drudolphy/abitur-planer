# Abitur-Planer BGY

Planungshilfe für Schülerinnen und Schüler des Beruflichen Gymnasiums (Fachrichtungen Technik und Wirtschaft) der BBS Idar-Oberstein – Harald-Fissler-Schule.

- zeigt die möglichen mündlichen Prüfungsfächer je Fächerkombination
- zeigt, welche Kurse in Block I eingebracht werden müssen
- berechnet mit eingegebenen Noten die beste Einbringung, eine Prognose zur Zulassung (13/2, Abiturprüfung) und die Abiturnote

Grundlage: Abiturprüfungsordnung RLP, Landesverordnung über das berufliche Gymnasium (je nach Eintrittsjahrgang) und die zugehörige Verwaltungsvorschrift.
Alle Eingaben bleiben im Browser der Nutzerin bzw. des Nutzers; es werden keine Daten übertragen.

Planungshilfe ohne Gewähr – verbindlich ist die Beratung durch die Oberstufenleitung.
